## [**Programa Simulador de cajero ATM**](cajero.py)

El programa que me decidí por realizar es un cajero automático de nombre ficticio, simula un sistema con contraseña para ingresar, en el que consta de 3 intentos, se utilizó un ciclo while para sacar al usuario si la contraseña fue ingresada erróneamente esas 3 veces, al ingresar correctamente el acceso permite ingresar dinero, retirar o salir de la sesion, pidiendo la contraseña de nuevo para volver a acceder, cada una de las opciones simula de manera correcta el cajero contando con dinero limitado el cual incrementa o decrementa respectivamente la operacion realizada, al terminar cada operacion, el usuario puede decidir si continuar con otro proceso o cerrar su sesion.
